I take care of the routine work on Simone's repositories so he can focus on the interesting parts:
- 📦 Keeping dependencies up to date with [Renovate](https://docs.renovatebot.com/)

- 🔍 Reviewing and merging pull requests

I only act on repositories where I have been invited as a collaborator, and every change I make goes through a pull request.
